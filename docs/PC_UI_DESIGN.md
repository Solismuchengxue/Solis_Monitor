# Solis Monitor PC 控制中心设计规范

> 状态：当前原生 WPF 实施基线
> 目标平台：Windows 11、原生 WPF、`.NET 10 x64`
> 兼容边界：WinForms 仅由显式 `--legacy-ui` 参数进入，不属于默认用户路径
> 视觉参考：Clash Verge 风格的深色控制台信息层级
> 更新日期：2026-07-31

## 1. 设计目标

PC 端不是副屏内容的放大版，而是单设备的配置、维护和诊断控制台。界面需要在一个
窗口中回答四个问题：

1. 副屏和依赖服务现在是否正常；
2. 当前可以执行哪些安全操作；
3. 配置修改会影响什么；
4. 操作成功、失败或等待时，下一步应该做什么。

视觉实现参考已确认的深色控制台设计：深海军蓝背景、图标导航、模块化圆角卡片、
清晰状态色和紧凑的信息密度。只参考信息层级与布局语言，不照搬其他产品功能。

## 2. 范围与边界

本轮统一以下界面：

- 控制中心外壳与左侧导航；
- 设备、服务、启动与托盘、固件更新、开发者模式五个页面；
- 设备向导、配对码、天气配置、夜间背光和恢复默认设置；
- Solis 功能产生的确认、成功、警告和错误提示。

以下系统界面保留 Windows 原生样式：

- 选择固件和保存文件的系统选择器；
- UAC 管理员授权；
- Windows 自身的任务栏、标题栏和系统通知。

本轮只改变视觉结构和呈现方式，不改变设备发现、配对、天气测试、开机启动、
设备控制、OTA、恢复默认设置及开发者模式的业务逻辑。

## 3. 设计令牌

界面继续跟随 Windows 深浅主题和系统强调色，但深色模式以参考图的深海军蓝层级为
基准，不再直接用系统灰色逐层混合。

| 令牌 | 用途 |
| --- | --- |
| `Canvas` | 主内容背景，最深层 |
| `Sidebar` | 左侧导航背景 |
| `Surface` | 一级卡片 |
| `SurfaceRaised` | 卡片内的状态块、输入区和操作块 |
| `Border` | 卡片和输入框的低对比边界 |
| `TextPrimary` | 标题、关键状态和主要数值 |
| `TextSecondary` | 说明、路径、时间和辅助信息 |
| `Accent` | 选中导航、主按钮、焦点和进度 |
| `Success` | 正常、已连接、测试成功 |
| `Warning` | 等待、未配置、需要操作 |
| `Danger` | 失败、不可逆操作、恢复默认设置 |

统一尺寸：

- 基础间距 8 px，卡片间距 12 px，页面左右留白 32 px；
- 一级卡片圆角 12 px，内部状态块圆角 8 px；
- 标准按钮 160×40 px，紧凑按钮 120×36 px，输入框高度 38 px；
- 页面内容基准宽度 760 px，随窗口可用宽度扩展；
- 最小窗口 1000×680，内容不足时只允许主内容区纵向滚动。

字体只使用 Windows 自带字体：

- 中文与正文：`Segoe UI`，不可用时回退系统消息字体；
- 图标：`Segoe Fluent Icons`；
- 页面标题 22 pt 粗体，卡片标题 11–12 pt 粗体；
- 正文 9.5–10 pt，次级说明 8.5–9 pt；
- 关键状态或数值 13–16 pt 粗体。

## 4. 公共组件

### 4.1 页面标题

每页顶部固定为“页面名 + 一句话说明”，左边界与下方卡片对齐。页面图标只出现在
左侧导航和摘要卡中，避免标题区重复装饰。

### 4.2 导航项

导航项使用 Fluent 图标和文字。选中项为强调色填充，未选中项透明，悬停只改变浅层
背景。版本号固定在侧栏底部；开发者入口解锁后显示在版本号上方。

### 4.3 状态卡

状态卡包含图标、标题、说明、状态标签和必要的主操作。不得把多行状态直接挤在普通
标签中。在线、正常、等待和故障使用统一状态标签。

### 4.4 设置行

每行分为左侧说明和右侧控件。所有右侧控件使用同一列宽和对齐基线；长路径或设备
信息允许两行，但按钮和状态不随文字漂移。

### 4.5 按钮

- 主按钮：强调色实心，用于继续、测试、保存、开始更新；
- 次按钮：深色表面与强调色边框，用于打开设置、重新扫描和普通操作；
- 幽灵按钮：用于返回和取消；
- 危险按钮：红色实心，用于恢复默认设置等不可逆操作；
- 禁用状态仍保持边框和文字可辨识。

### 4.6 输入控件

输入框、时间框和列表统一使用深色填充、1 px 边框、8 px 内边距和强调色焦点边框。
密码默认隐藏。错误优先在字段下方或弹窗状态区显示。

### 4.7 Solis 弹窗

所有自有弹窗采用统一结构：

1. 顶部图标、标题和说明；
2. 中间一张或多张内容卡；
3. 底部固定操作区；
4. 主按钮位于最右，取消位于其左；
5. 错误和成功状态在内容区内显示；
6. 只有需要用户确认的结果才阻塞关闭。

## 5. 页面设计

### 5.1 设备页

1. 顶部“当前设备”宽卡显示设备名、IP、RSSI、固件版本和连接状态；
2. 中部左侧“连接与安全”包含设备向导、配对状态和清除配对；
3. 中部右侧“显示与电源”包含亮度、夜间背光和远程重启；
4. 未配对时保留布局，只把不可用控件禁用并说明原因，避免页面跳动。

### 5.2 服务页

1. 顶部三张摘要卡：整体状态、副屏、最近检查；
2. “服务依赖链”：PC 后台 → 设备 API → 当前副屏；
3. “独立采集”双卡：Codex、天气；
4. “修复与导出”双操作卡：重启服务、复制诊断；
5. 最底部独立危险区：恢复默认设置。

链路节点必须同时显示名称、当前状态和关键详情，不能只显示大空框。

### 5.3 启动与托盘页

1. 顶部摘要卡显示当前启动策略；
2. 主卡只保留“静默启动”和“开机启动”两个设置行；
3. 底部说明卡解释关闭、最小化、托盘退出和管理员授权；
4. 开关直接显示“开/关”，变更后立即刷新摘要。

### 5.4 固件更新页

1. 顶部状态卡显示当前固件版本与更新状态；
2. 文件卡显示已选文件、版本、大小和 SHA-256 摘要；
3. 进度卡显示阶段标题、进度条和详细说明；
4. 未选择文件时只显示“选择固件”主按钮；
5. 校验完成后使用 Solis 确认弹窗，不直接开始烧录；
6. 文件选择器继续使用 Windows 原生界面。

### 5.5 开发者模式页

1. 顶部警示状态卡说明开发者模式已解锁；
2. “完整传感器树”作为主操作；
3. “关闭开发者入口”作为独立设置行；
4. 关闭后立即回到设备页并隐藏导航入口。

## 6. 弹窗设计

### 6.1 设备向导

固定为三步视觉流程，但不增加新的业务状态：

1. 选择“副屏已连接 Wi-Fi”或“配置/更换 Wi-Fi”；
2. 发现页显示扫描状态、设备卡片列表和重新扫描；
3. 选择设备后进入 6 位配对码弹窗。

设备列表不再使用裸 `ListBox` 文本行，改为设备卡片，设备名、IP、发现状态和配对
状态清晰分列。右上角系统关闭按钮保留，底部不重复放“关闭”。

### 6.2 配对码

- 设备名和说明置顶；
- 6 位数字输入框居中、大字号并限制长度；
- 非法输入在输入框下方原位提示；
- “取消”为次按钮，“确认配对”为主按钮。

### 6.3 天气配置

- API Host、API Key、经纬度分为三个字段组；
- 高德坐标说明作为普通带链接文字；
- “测试连接”和“保存”明确分离；
- 未测试或输入变更后禁用保存；
- 测试成功卡显示省市、天气和温度范围。

### 6.4 夜间背光

- 顶部开关控制是否启用；
- 中间并列显示开始和结束时间；
- 关闭时保留时间但禁用输入；
- 状态区说明按 PC 时区同步、保存后由副屏独立执行。

### 6.5 恢复默认设置

- 使用危险图标和红色强调；
- 清除项改为四条独立列表；
- 明确列出不会删除的内容；
- 默认焦点放在“取消”，危险按钮为“恢复并重新启动”。

### 6.6 通用结果与确认

用统一 `SolisDialog` 替换 Solis 业务中的原生 `MessageBox`。信息、成功、警告和错误
分别使用蓝、绿、琥珀和红色；确认弹窗默认焦点为取消；长文案自动换行。

## 7. 实施顺序

1. 建立共享设计令牌、圆角卡片、按钮、状态标签、输入框和弹窗基类；
2. 重做控制中心外壳和公共页面标题；
3. 重排设备、启动、固件和开发者页；
4. 按同一规范收敛服务页；
5. 重做设备向导、配对码、天气、夜间背光和恢复默认设置；
6. 替换 Solis 业务的原生 `MessageBox`；
7. 最后处理开发者模式中的上游对话框，避免影响普通模式主线。

## 8. 验收标准

- 100%、125%、150% DPI 下无重叠、裁切或按钮漂移；
- 所有页面标题与首张卡左边界一致；
- 所有设置行右侧控件宽度和基线一致；
- 最小窗口 1000×680 可用，纵向滚动只出现在主内容区；
- 深色和浅色模式均可读，强调色跟随 Windows；
- 禁用按钮仍可辨认；
- 设备向导、天气测试/保存、夜间背光、远程重启、服务重启、OTA 和恢复默认设置
  的业务行为保持不变；
- Solis 自有弹窗不再混用原生 `MessageBox`；
- 文件选择器和 UAC 保持系统原生样式；
- 自动化检查通过后，还必须用真实窗口截图与确认参考图并排检查。
