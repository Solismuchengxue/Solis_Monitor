# Solis Monitor 副屏界面规范

> 状态：当前实现基线
> 适用分辨率：800×480 横屏
> 更新日期：2026-07-25

## 1. 文档边界

本文记录 ESP32 副屏当前可运行界面的布局、字段层级、状态、素材和刷新规则。需求编号见根目录 `docs/REQUIREMENTS.md`，字段来源与 availability 见 `docs/PROTOCOL.md`，实现入口为：

- `tools/generate_assets.py`：生成静态背景、卡片、常驻图标和字体；
- `firmware/components/ui/ui.c`：绘制动态文字、进度条、状态图标和特殊模式；
- `firmware/components/ui_assets/`：保存生成后嵌入固件的 RGB565、RGBA565 和字库资源；
- `firmware/components/renderer/renderer.c`：像素、文字、进度条和透明图标绘制。

坐标原点位于屏幕左上角，X 向右、Y 向下。文中的文字 Y 坐标是字体基线，不是文字顶部。

## 2. 全局规则

### 2.1 画布与颜色

| 项目 | 当前规则 |
| --- | --- |
| 逻辑画布 | 固定 800×480，不做运行时缩放 |
| 像素格式 | RGB565；带透明度的图标使用 RGBA565 |
| 背景 | `reference/assets/background.png`，生成时覆盖半透明深色层 |
| 卡片圆角 | 10 px |
| 主文字 | 白色 |
| 次级文字 | 灰蓝色 `rgb(190, 204, 219)` |
| 强调色 | 青色 `rgb(76, 220, 255)` |
| 正常/连接 | 绿色 `rgb(68, 214, 165)` |
| GPU/断连状态 | 紫色 `rgb(136, 119, 255)` |

### 2.2 字体

界面使用 `reference/assets/HarmonyOS_Sans_SC_Medium.ttf` 的裁剪字库，只生成 20、24、56 px 三档：

| 字号 | 用途 |
| --- | --- |
| 20 px | 标题、名称、说明、状态和单位 |
| 24 px | 重点详情、容量、倒计时和普通结果 |
| 56 px | CPU/GPU 占用率、配对码和 AP 倒计时 |

新增中文、符号或状态文案前，必须把字符加入 `tools/glyphs.txt` 并重新生成资源；否则实机会缺字，而不是自动回退系统字体。

### 2.3 缺失值与长文本

- 不可用数值统一显示 `--`，不得把缺失值显示为 `0`。
- CPU、GPU 和硬盘名称最多取 28 个 UTF-8 字节；Wi-Fi SSID 最多 14 个 UTF-8 字节；Codex 项目名最多 24 个 UTF-8 字节；模型名最多 18 个 UTF-8 字节。
- 截断必须停在 UTF-8 字符边界，当前实现不附加省略号。
- 百分比进入 UI 前限制在 0%～100%。
- 硬盘最多显示 4 块；当前布局按 28 px 行距自上而下排列。

## 3. 电脑传感器页

### 3.1 静态卡片

| 区域 | 外框坐标 `(左, 上, 右, 下)` | 内容 |
| --- | --- | --- |
| CPU | `(24, 68, 388, 250)` | 图标、名称、占用率、主频、功耗、温度 |
| GPU | `(400, 68, 776, 250)` | 图标、名称、占用率、核心信息、显存信息 |
| 内存 | `(24, 262, 270, 456)` | 图标、已用/总量、占用率、温度 |
| 物理硬盘 | `(282, 262, 776, 456)` | 图标、逐盘名称、占用率、温度 |

顶部不设卡片，依次显示下载速度、上传速度和本机 Wi-Fi 状态。下载与上传图标已烘焙进背景；Wi-Fi 图标根据连接状态动态切换。

### 3.2 动态字段

| 区域 | 主要基线/位置 | 显示规则 |
| --- | --- | --- |
| 下载 | `(56, 40)` | `0.0 Mbps` |
| 上传 | `(272, 40)` | `0.0 Mbps` |
| Wi-Fi | 图标 `(570, 18, 28, 28)`；SSID `(610, 40)` | 连接时显示 `wifi_up` 与 SSID；断开时显示 `wifi_down` 与“无连接” |
| CPU | 名称 `(84, 108)`；占用率 `(40, 174)`；详情 `(190, 198)` | 详情顺序为主频、功耗、温度 |
| GPU | 名称 `(460, 108)`；占用率 `(416, 174)` | 第一行依次为主频、功耗、核心温度；第二行为显存已用/总量、显存温度 |
| 内存 | 标题 `(84, 302)`；容量 `(40, 360)`；详情 `(40, 414)` | 容量为已用/总量 GB；详情为占用率和温度 |
| 硬盘 | 标题 `(342, 302)`；首行基线 `342` | 左侧名称，右侧占用率和当前温度；无设备时显示 `--` |

电脑页不显示 Windows 网卡名、FPS 或 `PC ONLINE` 文案。

## 4. Codex 与环境页

### 4.1 静态卡片

| 区域 | 外框坐标 `(左, 上, 右, 下)` | 内容 |
| --- | --- | --- |
| 上下文 | `(24, 68, 420, 320)` | 项目、模型、推理强度、上下文占用 |
| 周额度 | `(432, 68, 776, 320)` | 主周额度与 Spark 周额度 |
| 环境与累计 Token | `(24, 332, 776, 456)` | 位置、天气、风向风力、账户累计 Token |

### 4.2 顶部状态

| 字段 | 位置 | 状态规则 |
| --- | --- | --- |
| 室内温度 | 图标 `(24, 18)`；文字 `(54, 40)` | 一位小数；不可用显示 `--` |
| 室内湿度 | 图标 `(220, 18)`；文字 `(250, 40)` | 整数百分比；不可用显示 `--` |
| Codex 状态 | `(620, 40)` | 只显示“CODEX 活跃”或“CODEX 不活跃”，不是应用在线状态 |

### 4.3 上下文卡片

- 标题基线为 `(40, 106)`。
- 项目名、模型和推理强度依次位于基线 142、176。
- `已用 K / 总 K` 与百分比位于基线 218，紧贴其下方的 `(40, 240, 364, 12)` 进度条。
- 项目、模型或上下文缺失时，各字段独立显示 `--`，保留最后有效值的策略由 PC 采集层决定。

### 4.4 周额度卡片

| 额度 | 标题与百分比基线 | 进度条 | 重置时间基线 |
| --- | --- | --- | --- |
| 主周额度 | `106` | `(448, 128, 312, 8)` | `160` |
| GPT-5.3-Codex-Spark | `218` | `(448, 240, 312, 8)` | `272` |

两组额度之间使用 `(448, 188, 312, 2)` 分隔线。百分比表示剩余额度，不是已用额度；重置时间必须位于对应进度条下方。额度不可用时显示“待更新”和“重置 --”。

### 4.5 天气与累计 Token

- 位置图标已烘焙在 `(40, 348, 28, 28)`，位置名基线为 `(80, 370)`。
- 中国地区位置使用“省·市·区”，例如“辽宁·大连·甘井子区”；固件状态保留
  63 个 UTF-8 字节，绘制时按 UTF-8 边界截到最多 36 字节，避免侵入右侧
  Token 区域。
- 天气图标动态绘制在 `(40, 378, 48, 48)`。
- 天气文字与最低/最高温位于 `(100, 402)`；风向与风力等级位于 `(100, 436)`。
- “账户累计 TOKEN”和数值共同以 X=500 左对齐，基线分别为 374 和 424。
- Token 自动使用原值、K、M 或 B；十亿及以上保留两位小数。

## 5. 特殊模式

特殊模式覆盖整个 800×480 画面，使用纯深色背景和 `(80, 64, 640, 352)` 的主卡片，不保留普通页面内容。

### 5.1 AP 配网

页面显示：

1. `Solis Monitor 配网`；
2. 实际热点名；
3. 固定地址 `192.168.0.1`；
4. `MM:SS` 格式的剩余时间；
5. `单击退出`。

进入该模式后，双击和再次长按不改变状态；单击退出。倒计时由固件状态每秒刷新。

### 5.2 发现与配对

未配对时显示“开启发现”、PC 端操作提示、6 位配对码、`N 秒后刷新`和“单击退出”。配对码每 60 秒刷新，倒计时到 0 后由配对服务生成新码。

配对成功时改为显示：

- `Solis Monitor 配对`；
- `已成功配对`；
- `PC 已获得设备访问权限`；
- `单击退出`。

发现或配对模式中忽略再次双击和长按，只允许单击退出。

## 6. 页面和按键

| 当前状态 | 单击 | 双击 | 长按约 5 秒 |
| --- | --- | --- | --- |
| 普通且背光亮 | 在电脑页与 Codex 页之间切换 | 进入发现模式 | 进入 AP 配网 |
| 夜间或失联熄屏 | 只唤醒 30 秒，不切页 | 首次按键事件只用于唤醒 | 首次按键事件只用于唤醒 |
| 发现/配对模式 | 退出 | 忽略 | 忽略 |
| AP 配网模式 | 退出 | 忽略 | 忽略 |

不提供自动轮换开关，普通页面仅由 GPIO21 单击切换。

## 7. 刷新模型

- 首次显示、页面切换和特殊模式进出采用整屏重绘。
- 正常 1 Hz 更新只恢复并重画动态区域，静态卡片和常驻图标来自背景资源。
- 电脑页有 5 个动态脏矩形；Codex 页有 4 个动态脏矩形。
- 特殊模式倒计时变化时当前仍整屏刷新，以保持实现简单并避免覆盖残留。
- 修改卡片边界、图标位置或动态文字位置时，必须同步检查静态背景范围和动态脏矩形，否则旧文字会残留或擦除卡片。

## 8. 素材与生成

### 8.1 素材来源

`reference/assets/` 是可编辑源素材目录。当前被固件直接使用的素材包括：

- 背景：`background.png`；
- 电脑页：`CPU.png`、`GPU.png`、`RAM.png`、`disk.png`、`download.png`、`upload.png`；
- Codex 页：`temper.png`、`humid.png`、`location.png`；
- Wi-Fi 状态：`wifi_up.png`、`wifi_down.png`；
- 天气：`m00.png`～`m26.png`；
- 字体：`HarmonyOS_Sans_SC_Medium.ttf`。

`loading.gif`、`wificonfig.png`、`WIFIhotpot.png` 和 PC 应用图标源不参与当前副屏普通页面生成，不应因“未引用”直接删除。

### 8.2 生成命令

在仓库根目录执行：

```powershell
python .\tools\generate_assets.py
```

默认输出到 `firmware/components/ui_assets/`。生成后至少运行：

```powershell
python -m unittest discover -s .\tools\tests
```

资源文件是固件构建输入。素材、图标尺寸、字库字符或布局常量变化后，必须重新生成并构建固件，不能只修改 PNG。

## 9. 实机验收清单

- 屏幕方向、RGB 顺序、右边界和四角无异常线条。
- 两个普通页面所有文字均在卡片内，无重叠、残影或缺字。
- 长 CPU/GPU/硬盘名、Wi-Fi SSID、Codex 项目名和模型名不会截断半个 UTF-8 字符。
- 所有缺失指标显示 `--`，不出现伪造的 0°C、0 W 或 0 GHz。
- Wi-Fi 连接/断开图标和 SSID/“无连接”同步变化。
- 上下文与 Spark 进度条对齐；两组额度的重置时间各归其位。
- 天气图标、天气文字、温度、风向和风力等级同时可见。
- AP 配网、发现、配对成功三种覆盖页排版正常，倒计时每秒变化。
- 特殊模式只允许单击退出，双击和长按不会重置倒计时或切换模式。
- 页面切换和 1 Hz 更新无旧文字残留。
