# Solis Monitor PC 端迁移基线

> 文档定位：PC 端迁移历史与兼容边界。迁移已经完成；当前桌面行为以
> [`DESKTOP_APP.md`](DESKTOP_APP.md)、[`PROTOCOL.md`](PROTOCOL.md) 和
> [`WEATHER.md`](WEATHER.md) 为准。

## 新的开发基线

PC 端以 `app/LibreHardwareMonitor` 中已经中文化并成功编译的 Libre Hardware Monitor v0.9.6 源码为基础继续开发。保留上游已有的硬件访问、传感器树、托盘、开机启动、日志、图表、桌面小工具和 HTTP Web 服务能力，不重新实现一套硬件监控内核。

最终程序名称为 **Solis Monitor**。默认界面使用精简、美化的新外壳；原始传感器树和高级功能不删除，在“开发者模式”中显示。

## 最新数据需求

| 模块 | 小屏幕需要的数据 | 归属与说明 |
| --- | --- | --- |
| CPU | 占用率、温度、主频、功耗 | PC 端从当前进程内的 LHM `Computer`/传感器模型读取 |
| GPU | 占用率、核心温度、核心主频、功耗、显存占用、显存温度 | 优先独立显卡；显存占用和主频都保留，显存温度按硬件支持情况提供 |
| 内存 | 占用率、温度 | 温度仅在硬件实际提供传感器时显示，否则为不可用 |
| 存储 | 选定 NVMe 温度 | 默认可自动选择，也应允许用户筛选 |
| 网络 | 选定网络设备的下载/上传速度 | 默认选择当前有效出口，UI 只展示一组上下行速度 |
| FPS | 帧率 | 数据源独立处理；小屏幕使用正确的 FPS 图标，不再复用硬盘图标 |
| Codex | 最后活动任务名称、当前上下文占用、周剩余用量 | 随 Codex 桌面版最后活动任务切换刷新 |
| 天气 | 地点、天气、室外最低/最高温 | PC 端获取并通过 HTTP 下发 |
| 室内环境 | DHT11 温度、湿度 | ESP32 固件本地读取，不经 PC 端采集 |

所有可选字段必须有独立的“可用/不可用”状态；不可用时小屏幕显示 `--`，不能用 `0` 冒充有效数值。CPU/GPU 大卡保留但缩小，给内存、FPS、NVMe、网络、Codex 和环境信息留出清晰空间。

## 从旧 Agent 继承的设计

以下内容已经经过实现或测试，迁移时优先复用其规则和测试思路：

- 设备数据使用版本化 JSON 协议，保留 `schema`、递增 `sequence`、`generated_at` 和逐字段 `availability`。
- 使用单一 1 Hz 发布器生成不可变快照，避免 UI 和 HTTP 各自采集而产生不一致。
- 单字段最后有效值最多保留 10 秒；超时后标记不可用。传输在线状态与业务字段可用状态分开。
- 本机管理入口与局域网设备入口隔离：管理操作只允许回环地址，ESP32 HTTP 接口使用设备令牌。
- 设备令牌使用 64 个十六进制字符（32 字节、256 位随机量）、Bearer 头、恒定时间比较和主动轮换；响应与控制请求限制为 4096 字节。
- 设置文件采用临时文件加原子替换，损坏时保留故障文件并生成新配置。
- 网络速度按网卡累计字节差值和单调时间计算，并处理重置、溢出、首个样本和异常时间间隔。
- 保留模拟数据模式，但仅作为开发者模式中的诊断工具，程序每次启动默认使用真实数据。

旧实现及测试链路已在重构后并入当前实现并清理，`old/pc_agent` 已下线。

## 不直接搬用的部分

- 不再通过 NuGet 引用 `LibreHardwareMonitorLib` 并建立第二套采集器；新功能直接复用 Solis Monitor 进程内已经打开的 LHM 对象模型。
- 不继续维护独立的 ASP.NET Core Agent 主程序。ESP32 指标 API 和管理 WebUI 应集成到桌面程序，并复用同一份指标快照。
- 旧协议需要新增 GPU 显存占用、显存温度和内存温度，同时保留 GPU 主频。修改协议时必须兼容当前 ESP32 固件或同步升级固件解析器。
- Codex 和天气的模拟值不能进入正式模式；必须有真实来源、刷新时间和失败状态。
- 不引入 WebSocket；ESP32 与 PC 继续使用已经验证的 HTTP 指标接口。
- AP 配网属于 ESP32 后续阶段，不混入本轮 PC 端重构。

## 迁移完成状态

1. 桌面进程已经建立统一指标快照，并从 LHM 模型映射 CPU、GPU、显存、内存、
   NVMe、FPS 和网络数据。
2. ESP32 HTTP 指标端点、设备令牌和兼容 schema 1 已并入桌面程序；固件解析和
   副屏界面已同步支持扩展字段。
3. Codex 最后活动任务、上下文、额度、账户累计 Token，以及天气数据和独立可用
   状态均已接入。
4. AP 配网、局域网发现与配对、设备控制和本地 OTA 已形成完整闭环。
5. 默认桌面入口已经迁移为原生 WPF 主窗口和 WPF 托盘；旧 WinForms 界面只作为
   显式 `--legacy-ui` 回退保留。
